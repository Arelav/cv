---
name: fontawesome
description: Look up Font Awesome React docs via context7 before using icons
---

Use context7 with library ID `/fortawesome/react-fontawesome` for Font Awesome React docs.

- Decorative icons must have `aria-hidden` — no `aria-label` on `<FontAwesomeIcon>`
- Components using `<FontAwesomeIcon>` must be `"use client"`
